# Progression Loops

## Ciclo curto

Produção de energia → Study → pequena melhoria → aumento de produção.

## Ciclo intermediário

Repetição → descoberta → Device → automação → maior frequência de tentativas.

## Ciclo longo

Acúmulo extremo → experimento → sacrifício da execução → recurso superior → próxima execução acelerada.

O [[MVP-0 Scope]] implementa o ciclo curto e o começo do intermediário. O ciclo longo será introduzido com a síntese da primeira partícula.

## Regra de aleatoriedade

Descobertas podem acontecer antecipadamente por sorte, mas sistemas essenciais devem possuir thresholds determinísticos. A sorte cria runs memoráveis; o azar não cria bloqueios permanentes.

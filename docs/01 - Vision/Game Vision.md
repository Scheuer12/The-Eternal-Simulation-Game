# Game Vision

The Eternal Simulation é um jogo incremental e idle, predominantemente textual, sobre descoberta, automação e crescimento exponencial.

O jogador encontra uma instalação abandonada e ativa um dispositivo capaz de condensar radiação cósmica em energia utilizável. O que inicialmente parece ser a recuperação de máquinas antigas se expande, futuramente, para a construção das estruturas fundamentais de um universo.

## Fantasia central

O jogador deixa gradualmente de operar processos individuais e passa a administrar sistemas de escala cada vez maior:

```text
energia → partículas → matéria → estruturas cósmicas → universo → tempo
```

Essa verdade não deve ser explicada de imediato. Informação também é recompensa.

## Pilares

1. Crescimento exponencial perceptível.
2. Transição satisfatória do manual para o automático.
3. Sorte capaz de acelerar, mas nunca bloquear, a progressão essencial.
4. Mistério científico apresentado por instrumentos e registros incompletos.
5. Sistemas configuráveis e testáveis, evitando balanceamento preso ao código.

## Direção visual

- dark mode;
- laboratorial e levemente futurista;
- baseada em texto, painéis e sinais;
- azul frio para energia;
- âmbar para alertas;
- violeta para descobertas e elementos inexplicados.
